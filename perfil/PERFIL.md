# Perfil de viagem — Rick

> Memória curada deste repo. Qualquer skill de planejamento lê este arquivo
> **antes** de perguntar qualquer coisa, e escreve nele **depois** de aprender
> qualquer coisa. O objetivo é que, com o tempo, um prompt de uma linha seja
> suficiente para gerar um roteiro que já parece feito sob medida.

Última atualização: 2026-09-12
Viagens que alimentaram este perfil: Itália 2027 (em planejamento)

## Como ler as marcações

Cada afirmação carrega o quanto se pode confiar nela:

- **(hipótese)** — inferido de um único sinal indireto. Vale usar como default,
  mas confirme se a decisão for cara ou irreversível.
- **(provável)** — observado mais de uma vez, ou dito uma vez de forma clara.
  Use sem perguntar.
- **(confirmado)** — dito explicitamente, ou repetido em viagens diferentes.
  Tratar como regra. Só mude se ele contradisser.
